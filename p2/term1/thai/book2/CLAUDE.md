# เกมคำภาษาไทยมาตรฐานและภาษาถิ่น (ป.2 เล่ม 2)

## ไฟล์หลัก (Source of Truth)

**`คำภาษาไทยมาตรฐานและภาษาถิ่น.xlsx`** คือไฟล์หลักของคลังคำทั้งหมด
ชีต `คำภาษาถิ่น` คอลัมน์: `ภาษาไทย | ภาษาถิ่นเหนือ | ภาษาอีสาน | ภาษาถิ่นใต้`

**ถือว่า excel ถูกต้องเสมอ** ไฟล์เกมทุกชุดต้องสะกดคำตรงกับ excel

## กฎการทำงาน

1. **เกม → excel**: ถ้าชุดไหนไป research คำเพิ่มจากอินเทอร์เน็ต ต้องเอาคำใหม่นั้น
   กลับมาเพิ่มใน excel ด้วยทุกครั้ง อย่าให้คำใหม่ค้างอยู่แต่ในไฟล์เกม

2. **excel → เกม**: เวลาแก้คำใน excel ต้องไล่แก้ในไฟล์เกมทุกชุดที่มีคำนั้นให้ตรงกัน
   ทั้ง `central`/`th`, `nuea`, `isan`, `tai`

3. **สะกดต่างจาก excel**: ถ้า search แล้วเจอคำที่สะกดไม่ตรงกับที่มีใน excel
   **ให้มาถามกิ๊บก่อน** ห้ามแก้ excel เองโดยพลการ

4. **คำถิ่นที่มีหลายรูป**: excel เก็บเป็น `คำหลัก (คำรอง)` หรือ `คำ ก / คำ ข`
   ไฟล์เกมชุดที่แสดงคำเป็นตัวเลือก (set1–set4) ให้ใช้สตริงเต็มตาม excel
   ส่วน set5 ที่ฝังคำในประโยค ให้เลือกใช้รูปใดรูปหนึ่งที่มีอยู่ใน excel เท่านั้น

## โครงไฟล์เกม

| ไฟล์ | รูปแบบ | ตัวแปรคลังคำ | จำนวน |
|---|---|---|---|
| `g2-thai-dialect-game_set1.html` | จับคู่ 3 ถิ่น (dropdown) | `window.QUIZ_DATA.questions` (`central/nuea/isan/tai` + `pic`) | 33 คำ |
| `g2-thai-dialect-game_set2.html` | เลือกคำถิ่นจาก dropdown | `window.QUIZ_DATA.questions` | 33 คำ |
| `g2-thai-dialect-game_set3.html` | จับคู่ความหมาย | `window.WORD_BANK` (`th/nuea/isan/tai`) | 23 คำ |
| `g2-thai-dialect-game_set4.html` | เติมตารางคำ | `window.WORD_BANK` | 33 คำ |
| `g2-thai-dialect-game_set5.html` | เติมคำในประโยค | `window.SENTENCE_BANK` (`pre/word/post/ans/th`) | 78 ประโยค / 29 คำ |

- set1, set2 ใช้ภาพจากฟิลด์ `pic` ลำดับการหา: `images/<pic>.png` → base64/SVG ใน `window.PICS` → placeholder
  **เพิ่มคำใหม่ในสองชุดนี้ต้องเพิ่มทั้งแถวคำถามและภาพใน `window.PICS` ของทั้งสองไฟล์**
- 23 คำแรกใช้ภาพ PNG base64, 10 คำใหม่ใช้ภาพวาด SVG (ต้นฉบับอยู่ใน `images/*.svg`)
- set3 ยังมีแค่ 23 คำ ยังไม่ได้เพิ่ม 10 คำใหม่; set5 ยังไม่มีประโยคของ เดิน/ไม่/สวย/เล่น
- set5 ฟิลด์ `th` ต้องตรงกับคอลัมน์ `ภาษาไทย` ใน excel เป๊ะ ๆ (ใช้ match ความหมาย)

## ข้อควรระวัง

- ถ้ามีไฟล์ `~$คำภาษาไทย....xlsx` อยู่ แปลว่า excel เปิดค้างใน Excel อยู่
  บอกกิ๊บให้ปิดก่อน ไม่งั้นการ save ทับจากหน้าต่างที่เปิดค้างจะลบงานที่แก้ไป
- สำรองไฟล์ก่อนแก้ทุกครั้ง (โฟลเดอร์นี้ไม่ใช่ git repo ย้อนกลับไม่ได้)
